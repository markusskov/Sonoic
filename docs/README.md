# Sonoic Docs

This folder keeps public, durable project docs. Short-lived working notes, agent scratchpads, and private planning should not live in the public repository.

## Public Docs

- [Roadmap](ROADMAP.md) - current priorities and open product questions
- [Reliability](RELIABILITY.md) - truthfulness, stale-state, and validation rules
- [Security And Privacy](SECURITY.md) - network, token, storage, and secret boundaries
- [TestFlight Readiness](TESTFLIGHT_READINESS.md) - release checklist, preflight, OAuth, privacy, and hardware validation gates
- [TestFlight Tester Guide](TESTFLIGHT_TESTER_GUIDE.md) - tester setup, smoke pass, beta boundaries, and bug report instructions
- [App Store Review Notes](APP_STORE_REVIEW_NOTES.md) - non-secret review notes template, permissions, and beta boundaries
- [Sonos OAuth Setup](sonos-oauth-dev-setup.md) - Worker-backed Sonos OAuth setup for development
- [Manual Host Refresh Verification](manual-host-refresh-verification.md) - device checklist for LAN fallback and room refresh behavior
- [Apple Music Roadmap](apple-music-roadmap.md) - source-browsing and Sonos-owned playback direction
- [Sonos-Native Playback Research](sonos-native-playback-research.md) - playback ownership notes and research boundaries

## What Does Not Belong Here

- personal Xcode state, provisioning details, or local machine notes
- one-off chat transcripts or temporary execution plans
- secrets, API keys, access tokens, refresh tokens, or private Sonos credentials
- generated summaries that duplicate hand-written source-of-truth docs
